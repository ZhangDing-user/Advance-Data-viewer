运行

Run

  1. 把 exe 放到任意目录（不需要旁边有别的文件）。
  2. 双击运行。会弹出一个黑色命令行窗口，不要关——关掉就等于退出程序。
  3. 浏览器随后自动打开 http://127.0.0.1:8770；首次启动约 4~5 秒。
  4. 点文件名右侧的 ... 选数据文件；数据目录可在 config.json 的 roots 里改。
  1. Put the exe in any folder; it needs no companion files.
  2. Double-click it. A console window appears — keep it open, closing it quits the program.
  3. The browser opens http://127.0.0.1:8770; the first start takes about 4-5 seconds.
  4. Click ... next to the file name to pick data; set your data roots in config.json.

包含

Includes

  • 最多 7 条独立 Y 轴叠加
  • 派生通道表达式，含零相位滤波 lp0 / hp0
  • A–B 区间测量、逐循环、分段统计，结果可存为通道
  • 相位差与曲线拟合（单频 DFT，用真实时间戳）
  • HTTP 接口 / 28 个工具，可交给外部 AI 驱动
  • Up to 7 overlaid independent Y axes
  • Derived-channel expressions with zero-phase lp0 / hp0
  • A-B measurement, per-cycle and per-segment stats, savable as channels
  • Phase difference and curve fitting (single-bin DFT on real timestamps)
  • HTTP interface with 28 tools, drivable by an external AI agent
