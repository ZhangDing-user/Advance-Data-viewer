启动
----
整个程序就是一个 exe（约 47 MB），**单文件、免安装**：随便拷到哪个目录双击都行，
不用连带任何文件夹。

双击 “Advanced Data Viewer_v1.10.13.exe”。会出现一个黑色命令行窗口（不要关，关掉就等于退出程序），
浏览器随后自动打开 http://127.0.0.1:8770 。

· 每次启动约 4~5 秒：单文件版要先把运行库解包到 %TEMP%\_MEIxxxx 再起来，属正常现象
· 正常关闭会自动清掉那个临时目录；如果是任务管理器强杀，可能留下 _MEIxxxx，可手工删除
· 文件名带版本号（Advanced Data Viewer_v1.10.13.exe）：升级时把新号的 exe 放进来、
  旧的留作备份即可，config.json / colors.json / last.json 不用动，名字换了也照样读得到

第一次运行会在本目录生成：
  config.json    端口、数据根目录、可选的大模型接口
  last.json      上次打开的文件（仅记录，默认不自动打开）
  colors.json    每条曲线的自定义颜色
  exports/       导出的 PNG / CSV

找不到数据文件
--------------
用记事本打开 config.json，把 roots 改成你的数据目录：
  "roots": ["D:////试验数据"], "default_dir": "D:////试验数据"
或者启动时指定：
  "Advanced Data Viewer_v1.10.13.exe" --data-root "D://试验数据"

端口被占用
----------
  "Advanced Data Viewer_v1.10.13.exe" --port 8780

看版本号
--------
  "Advanced Data Viewer_v1.10.13.exe" --version   （输出 Advanced Data Viewer v1.10.13 后退出）
也可以看接口：http://127.0.0.1:8770/api/tools 里的 version 字段

用法要点
--------
· 界面语言：标题栏右上角 “EN / 中文” 一键切换（记住选择）；也可用 ?lang=en 或 ?lang=zh 直接指定
· 启动后是空白界面，需要自己点 “...” 选文件（不会自动载入上次的数据）
· 左键从左向右拖 = 放大到该区间；从右向左拖 = 等比缩小
· 按住右键拖动 = 沿 X 轴平移（缩放级别不变）
· 滚轮缩放，双击 / Esc / “全局显示” 按钮复位
· **右键单击**（不拖动）= 弹出菜单：比较相位差 / 全局显示 / 导出 PNG / 导出 CSV
  右键**拖动**仍然是平移，两者靠“有没有移动”区分
· 放大深度只受采样间隔限制（窗口内至少留 6 个原始点），没有固定倍数上限：
  8 kHz 的爆发段能一路放到微秒级；1 秒一个点的停歇段会停在那里，那是数据本身没有更细的东西
· 配色：单条改色会记住（存 colors.json）；批量改色只影响当前画面，不写盘
· Graph Definition 里可选通道、叠加多条曲线、改颜色，最多 7 个 Y 轴
· 同一张图可叠加多条曲线，并让每条曲线用自己的 Y 刻度：Graph Definition 里勾“独立 Y 轴”
  轴左右分列（前一半在左、其余在右），第 1 条贴在最里侧，网格跟着第 1 条走；
  每条轴有自己的竖线、3px 刻度线和竖排轴名（写全名带单位，左逆时针右顺时针，按曲线上色）
  最多 7 条曲线 = 7 条独立轴；曲线多时刻度自动变稀（5~6 个/轴）
  注意：同一图里至少要有 2 条曲线才有独立刻度可言；只有 1 条时勾选框会置灰并标注
  “（需 ≥2 条曲线）”，点 Channel 右边的 + 叠加一条即可；点 Ok 后提示会说明是否已生效
  AI 侧等价写法：set_y 追加 7 个通道，然后 set_panels(count=1, overlay=true)

· 派生通道（用表达式造新通道，如 应力 = 载荷 / 面积）：
  工具栏 ƒ 按钮，或画布右键「新建派生通道…」→ 写表达式 → 试算看 min/max/mean → 创建并画图
  通道名带空格要加双引号，比如 "Ch A-1" / 19.63；下面的通道清单点一下就插入
  函数：abs sqrt log exp min max diff integ lp hp movmean shift
        lp0 / hp0 是零相位版本（正反各滤一次，相位不滞后）；判相位/损耗必须用它，
        单向的 lp/hp 会带 −atan(f/fc) 的假相位，fc=40 时 10 Hz 就少 14°
  建好后它和原生通道一样能画、能统计，也能被别的表达式引用（带 ƒ 标记）
  对话框上半部分是已有派生通道的列表：每行可以 画图 / 编辑 / 删除
  编辑会回填表单，改名会删掉旧通道；删除要再点一次确认，并会把它从所有图上摘掉

· 光标与区间测量：
  画布右键 →「设为光标 A」「设为光标 B」（在点击位置放线），光标线 6 px 内可拖动
  状态栏显示 A / B / Δ / 1/Δ；右键「测量 A–B 区间…」打开右侧测量面板
  面板给每个通道的 min/max/均值/峰峰/RMS/σ/过零/周期/频率/斜率/有效率，可导出 CSV
  面板是常驻侧栏，打开时画布自动让出位置；关掉后恢复

· 相位差（测量面板）：
  图上画出至少 2 条曲线，设置 A/B 后，面板自动给出比较通道相对参考通道的相位角与时差
  参考/比较通道可切换；频率留空自动估计，也可填已知频率（Hz）
  正相位表示比较通道领先；“详细比较…”可查看多通道的幅值比及拟合优度

· 曲线拟合（测量面板）：
  选通道和函数类型：线性趋势、2–6 阶多项式趋势，或单频正弦
  点「计算函数」得到方程、R²、RMSE；「复制函数」可复制方程
  「叠加拟合曲线」将 A/B 区间的结果存成新通道并画在原图上，源数据不变
  多项式函数里的 u=(x-x_origin)/x_scale 是时间坐标变换；代入原始 x 才得到 y
  R² 较低时请换函数类型或区间，例如多项式不适合拟合多个完整正弦周期

· 逐循环：
  选通道 + 切法（峰谷配对 / 同向过零）→ 算循环
  汇总行给：循环数 · 平均周期 · 周期变异系数 · 平均幅值 · 半程幅值漂移
  表格逐循环列 t0 / T / 幅值 / 均值 / 峰峰 / 上升占比

· 分段统计：
  选通道 + 切法（按时长 / 按周期）+ 每段秒数 → 分段统计
  汇总行给段数与首末段的均值/峰峰变化率；表格逐段列 起止 / 点数 / 均值 / 峰峰 / 幅值 / RMS
  按时长切段任何数据都能用，**不要求文件里带段标记**
  AI 侧还有 by=boundaries（自己给边界）、by=flag（只有文件恰好带段标记通道时才可用）

· 结果存为通道（三段各自都有一个「存为通道」按钮）：
  先在面板最下面「名字」框填个名字（留空自动命名 meas1 / cyc1 / seg1），
  选好要存哪个量（均值 / 峰峰 / 幅值 / RMS / 最小值 / 最大值 …），点「存为通道」
  生成的通道带 Σ 和「结果」标：能画、能参与表达式、能继续统计，但不能改表达式（删掉重算即可）
  测量结果 → 区间内一条定值线；逐循环 / 分段结果 → 一段一台阶的阶梯线

AI 接管（界面里没有对话框，由外部 AI 直接调接口）
-------
接口清单：http://127.0.0.1:8770/api/tools      （28 个工具的 OpenAI 兼容定义）
状态：    http://127.0.0.1:8770/api/state
一句话下指令（不联网、不要 API Key）：
    curl -X POST http://127.0.0.1:8770/api/command -H "Content-Type: application/json" -d "{\"text\":\"打开 sample_01，画第 1 通道对时间，缩到 600-1200 秒\"}"
Python 示例：源码目录 demo_agent.py、smoke_agent.py（98 项断言：97 通过 / 1 跳过）
接管成功时，界面右上角会显示“AI 接管中”。
若系统设了 HTTP 代理，记得把 127.0.0.1 加进 NO_PROXY（附带的两个示例脚本已自行绕过代理）。

比较相位差（跨通道，先缩到要比较的区间，再说一句话就行）
-------
界面里也能做：**右键单击绘图区 → 比较相位差…**，弹出对话框后：
    区间默认“跟随当前视图”（也可以关掉手填两个时间）
    选参考通道、勾要比较的通道（默认勾当前图上那些）、频率留空自动找主频
    点“计算”，下面直接出表：幅值 / 相位差 / 时差 / 幅值比 / r²
也可以让 AI 说一句：
    curl -X POST http://127.0.0.1:8770/api/command -H "Content-Type: application/json" -d "{\"text\":\"比较第 1 和第 2 通道的相位差\"}"
或者直接调工具：
    {"tool":"phase_diff","args":{"channels":["Force","Disp"],
                                 "reference":"Force","x0":600,"x1":1200}}
返回值里：phase_diff_deg 正数 = 该通道领先参考；time_shift_ms 是同一件事的毫秒表示；
r2 是单频正弦拟合优度——r2 很低（比如一条恒定不变的通道）说明相位数没有意义，别硬读。
不给 x0/x1 就用当前视图；不给 freq 就自动找主频（过零粗估 + |X(f)| 细化）。

注意
----
单文件版只需要这一个 exe，不需要 _internal 文件夹。
只要不删同目录的 config.json，换机器后记得把它里面的 roots 改成新机器的数据路径。
